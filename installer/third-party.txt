# The third-party programs that the RetroArchiver installer ships with.
#
# It is the only list: `make setup` (with installer/third_party.py) checks the
# hashes, prepares the files in build/third-party/<id>/ and writes their versions in
# build/third-party/third_party.nsh, which retroarchiver.nsi includes. The files are NOT
# in the repo: they are downloaded by hand (from a PC with Internet) and put in the
# THIRDPARTY folder (default installer/third-party/, ignored by git).
#
# To add a component: one line here and a Section in
# retroarchiver.nsi that uses build/third-party/<id>/ and ${T_<id>_VERSION}.
#
# One field per column, separated by "|":
#   id        short name, no spaces (folder in build/third-party and name of the defines)
#   name      as the user sees it
#   version
#   file      the name of the downloaded file
#   sha256    the hash of the downloaded file
#   url       where to download it
#   root      for a zip: the folder in the zip that becomes the install
#             folder ("." = the whole zip); loose files at the top of the
#             zip (licence, readme) are always included. "-" for a file to
#             use as it is (an installer)
#   license   the known one, with where to read it
#   license_file  the original licence text, in installer/licenses/
#             (in the repo); "-" if there is no text to redistribute (the
#             Microsoft runtime: the terms are in its installer). The setup
#             puts it in licenses\ and, for a zip, also next to the program
#
# The full credits, for users of RetroArchiver: THIRD-PARTY-NOTICES.txt
# at the repo root.
#
# The hashes are those of the files downloaded on 16-17/10/2026 and tested
# on the XP VM.
